# Weekly Review

Use [[Template - Weekly Review]] para criar a revisão de cada semana.

## Perguntas que importam

- O que gerou conversa real?
- Qual tarefa consumiu tempo sem produzir aprendizado?
- Que suposição foi invalidada?
- Qual é o gargalo atual: descoberta, pesquisa, mensagem, resposta ou proposta?
- Qual única melhoria deve entrar na próxima semana?

## Dados de apoio

Execute `npm run brain:sync` e consulte [[CRM Snapshot]] antes de preencher a revisão.
